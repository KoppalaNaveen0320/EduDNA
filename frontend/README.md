# EduDNA Frontend Dashboards

This directory contains the user interface portals for EduDNA:

1. **Student Dashboard (`/student_dashboard/`)**:
   - Visualizes student's personalized Learning Genome (DNA).
   - Concept mastery progression, strengths, and recommended practice.

2. **Teacher Dashboard (`/teacher_dashboard/`)**:
   - Class-wide overview, learning style distributions, and concept mastery heatmap.
   - At-risk student flags and recommended classroom interventions.

3. **Parent Dashboard (`/parent_dashboard/`)**:
   - Academic growth over time, study habit consistency, and AI learning tutor updates.

4. **Shared Assets (`/shared/`)**:
   - Shared design system (`styles.css`), unified API client (`api.js`).

---

## Quick Start
Open `index.html` in your web browser or serve locally:
```bash
npx serve .
# Or
python -m http.server 3000
```
